# 人工验收清单

这份清单用于验证真实 Windows 输入是否能从 Hook 进入 SQLite，再实时刷新到 Vue 页面。自动化测试无法模拟真实物理输入，因此接手 agent 或发布前应执行一次。

## 启动

- [ ] 执行 `npm run tauri dev`，程序正常打开
- [ ] 顶部状态显示“本地实时数据”，不是“演示数据”
- [ ] 记录开始前的“总按键数”和“鼠标操作”

## 键盘

- [ ] 按一下 `A`，`A` 次数增加 1
- [ ] 长按 `A` 约 3 秒，默认模式只增加 1 次
- [ ] 松开后再次按 `A`，次数再次增加 1
- [ ] 按 `Shift`、`Ctrl`、`Space`，对应按键计数正确
- [ ] 快速使用组合键时，界面不会卡顿或崩溃

## 鼠标

- [ ] 左键点击，左键次数增加
- [ ] 右键点击，右键次数增加
- [ ] 滚轮上下滚动，滚轮统计增加
- [ ] 如果设备有侧键，侧键统计增加

## 控制和持久化

- [ ] 点击“正在记录”后变为“已暂停”
- [ ] 暂停状态下按键和鼠标操作不会增加计数
- [ ] 点击“已暂停”恢复记录后，计数继续增加
- [ ] 清空数据后界面显示为零或“暂无”
- [ ] 关闭并重新打开应用，历史数据仍然存在
- [ ] 切换“今天 / 本周 / 本月”，统计范围会变化

## 限制场景

- [ ] 普通权限下的常规桌面程序可以统计
- [ ] 高权限程序、UAC 安全桌面和反作弊软件限制已记录
- [ ] 输入监听失败时，主界面仍可打开并显示可理解的状态
