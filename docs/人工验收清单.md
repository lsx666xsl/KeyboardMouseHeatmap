# 人工验收清单

这份清单用于验证真实 Windows 输入是否能从 Hook 进入 SQLite，再实时刷新到 Vue 页面。自动化测试无法模拟真实物理输入，因此接手 agent 或发布前应执行一次。

## 启动

- [ ] 执行 `npm run tauri dev`，程序正常打开
- [ ] 顶部状态显示“本地实时数据”，不是“演示数据”
- [ ] 记录开始前的“总按键数”和“鼠标操作”

## 键盘

- [ ] 按一下 `A`，`A` 次数增加 1
- [ ] 长按 `A` 约 3 秒，默认模式只增加 1 次
- [ ] 松开后再次按 `A`，次数再次增加 1
- [ ] 按 `Shift`、`Ctrl`、`Space`，对应按键计数正确
- [ ] 快速使用组合键时，界面不会卡顿或崩溃

## 鼠标

- [ ] 左键点击，左键次数增加
- [ ] 右键点击，右键次数增加
- [ ] 滚轮上下滚动，滚轮统计增加
- [ ] 如果设备有侧键，侧键统计增加

## 控制和持久化

- [ ] 点击“正在记录”后变为“已暂停”
- [ ] 暂停状态下按键和鼠标操作不会增加计数
- [ ] 点击“已暂停”恢复记录后，计数继续增加
- [ ] 清空数据后界面显示为零或“暂无”
- [ ] 关闭并重新打开应用，历史数据仍然存在
- [ ] 切换“今天 / 本周 / 本月”，统计范围会变化
- [ ] 打开日历，选择开始日期和结束日期后点击“应用范围”
- [ ] 自定义范围包含起止日期当天的数据，且不包含范围外数据
- [ ] 开始日期晚于结束日期时显示错误，不发起无效查询

## 系统托盘

- [ ] 应用启动后任务栏通知区域出现 KeyPulse 图标
- [ ] 点击“打开 KeyPulse”可以显示并聚焦主窗口
- [ ] 点击主窗口关闭按钮后窗口隐藏，进程仍在托盘运行
- [ ] 左键点击托盘图标可以重新显示并聚焦主窗口
- [ ] 点击“暂停/继续记录”后，主界面状态同步变化
- [ ] 点击“清空本地统计”后，今日数据归零或显示“暂无”
- [ ] 点击“退出 KeyPulse”后进程正常结束

## 限制场景

- [ ] 普通权限下的常规桌面程序可以统计
- [ ] 高权限程序、UAC 安全桌面和反作弊软件限制已记录
- [ ] 输入监听失败时，主界面仍可打开并显示可理解的状态
- [ ] 监听不可用时顶部显示“监听不可用”，记录按钮不可点击，历史统计仍可查看

## 安装包

- [ ] 使用 MSI 安装包完成安装并启动应用
- [ ] 使用 NSIS 安装包完成安装并启动应用
- [ ] 卸载后程序文件和快捷方式按预期移除
