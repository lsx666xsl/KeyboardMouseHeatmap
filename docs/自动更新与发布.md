# 自动更新与版本发布

应用通过 Tauri v2 官方 updater 插件实现自动更新：检查 GitHub Releases 上的 `latest.json`，发现新版本后提示下载、一键安装并自动重启。

## 为什么只有 NSIS（重要）

打包目标固定为 `["nsis"]`。v0.1.1 曾同时产出 MSI，实测发现 MSI 是全机器安装（写入 `C:\Program Files`），**静默更新时必须弹 UAC 管理员授权，容易卡死在“正在准备安装”**；而 NSIS 用户级安装（`%LOCALAPPDATA%`）全程免管理员权限，静默更新顺畅。**不要把 MSI 加回打包目标**，否则“未安装/绿色版”用户的更新会退回 MSI 路径重新踩坑。

## 更新如何工作

- **检查时机**：主窗口启动 2.5 秒后、运行期间每 6 小时、或托盘菜单「检查更新」（忽略已点过“稍后”的版本）。
- **升级流程**：发现新版本 → 右上角卡片提示 → 点击「立即更新」→ 后台下载（显示进度）→ 自动安装 → 应用自动重启。
- **跳过提醒**：点「稍后」只隐藏当前版本；发布更新的版本后仍会再提醒。
- 开发模式（`npm run dev`）与 keys-mini / keys-overlay 窗口不执行检查。

## 安装向导与数据位置

- 手动双击 `setup.exe` 会弹出完整安装向导：欢迎页 → **选择安装目录**（默认 `%LOCALAPPDATA%\Keyboard Mouse Heatmap`，可通过 Browse 换到任意盘符）→ 安装 → 完成。自动更新走静默模式，会自动跳过这些页面，无需用户操作。
- 数据库默认存在 **exe 同目录的 `keypulse-data` 文件夹**（便携式优先）；目录不可写时自动回退 `%APPDATA%`。设置面板可随时在两个位置间切换，切换时自动把现有数据库完整复制到新位置（旧位置文件保留作备份），确认后应用自动重启生效。
- 升级（静默 `/P /UPDATE`）不运行旧卸载器、不删安装目录里的任何额外文件，`keypulse-data` 数据天然安全；手动卸载时卸载器也只删自己的文件。
- 卸载向导底部有「删除应用程序数据」复选框（**默认不勾选**）：勾选后除 `%APPDATA%`/`%LOCALAPPDATA%` 的应用数据外，也会一并删除安装目录里的 `keypulse-data`（`src-tauri/hooks/keypulse.nsh` 的 POSTUNINSTALL 钩子实现）；不勾选则数据永远保留。

## 签名密钥（重要，勿丢）

更新包使用 ed25519 签名校验，公钥已写入 `src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`。

- 私钥位置：`C:\Users\579\.tauri\kmh-updater\keypulse.key`（密码在同目录 `key.pass`）
- **私钥 + 密码都不能丢失**：丢失后将无法给新版本签名，只能重新生成密钥对、替换公钥后重新发布一个全量版本。
- 私钥绝不能提交进仓库；换机器时请一并备份 `keypulse.key` 与 `key.pass`。

## 首次配置 GitHub Actions Secrets

发布工作流 `.github/workflows/release.yml` 会在推送 `v*` tag 时自动构建并发布 Release，需要仓库配置两个 Secret（Settings → Secrets and variables → Actions）：

```bash
gh secret set TAURI_SIGNING_PRIVATE_KEY          --repo lsx666xsl/KeyboardMouseHeatmap < C:\Users\579\.tauri\kmh-updater\keypulse.key
gh secret set TAURI_SIGNING_PRIVATE_KEY_PASSWORD --repo lsx666xsl/KeyboardMouseHeatmap < C:\Users\579\.tauri\kmh-updater\key.pass
```

（未装 gh 时也可在网页端手动粘贴，注意粘贴的是 key 文件内容本身，含多行。）

## 发布一个新版本

1. 同步修改三处版本号（保持 v 前缀前的数字一致）：
   - `src-tauri/tauri.conf.json` → `version`
   - `src-tauri/Cargo.toml` → `version`
2. 提交并推送 tag（tag 必须等于 `v` + 配置文件里的版本号，工作流按它发布）：

```bash
git add . && git commit -m "chore: release v0.1.1"
git tag v0.1.1
git push origin main --tags
```

3. 等 GitHub Actions 完成（约 5–10 分钟），在 Releases 页面确认产物：
   - `Keyboard Mouse Heatmap_<版本>_x64-setup.exe` + `.exe.sig`
   - `latest.json`
4. 老用户端下次自动检查即可收到更新；新用户直接下载 Release 安装包。

## 本地手工验证（可选）

带签名环境变量执行完整打包，可检查 `latest.json` 与 `.sig` 是否随产物生成：

```bash
cd /f/TauriProject/KeyboardMouseHeatmap   # Git Bash
export TAURI_SIGNING_PRIVATE_KEY="$(cat /c/Users/579/.tauri/kmh-updater/keypulse.key)"
export TAURI_SIGNING_PRIVATE_KEY_PASSWORD="$(cat /c/Users/579/.tauri/kmh-updater/key.pass)"
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/`。
