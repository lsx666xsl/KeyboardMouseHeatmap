# 技术决策记录

## ADR-001：选择 Tauri + Rust

- 日期：2026-09-04
- 状态：已确认
- 决策：使用 Tauri 2 作为桌面容器，Rust 作为原生后端

原因：项目需要全局监听键盘和鼠标，同时需要较丰富的现代化可视化界面。Tauri 可以使用 Web 技术制作界面，Rust 负责 Windows 原生输入和本地数据，体积和资源占用也适合常驻工具。

## ADR-002：前端使用 Vue 3 + TypeScript + Vite

- 日期：2026-09-04
- 状态：已确认
- 决策：使用 Vue 3、TypeScript 和 Vite

原因：当前 `F:\TauriProject\SerialTool` 已采用类似前端组合，可以复用使用经验；Vue 适合快速组织仪表盘、SVG 模板和响应式数据。

## ADR-003：数据库使用 SQLite

- 日期：2026-09-04
- 状态：已确认
- 决策：统计数据只存储在本机 SQLite

原因：数据量小、无需服务器、离线可用，适合隐私优先的个人工具。数据库保存聚合结果，不保存原始输入流。

## ADR-004：键盘模板使用 SVG

- 日期：2026-09-04
- 状态：计划采用
- 决策：使用 SVG 绘制键盘和鼠标模板，通过 CSS 变量和 Vue 数据绑定控制颜色与数字

原因：SVG 适合精确布局、悬停交互、响应式缩放和自定义主题，也方便支持 ANSI、ISO 和笔记本键盘布局。

## ADR-005：默认采用物理按键统计模式

- 日期：2026-09-04
- 状态：计划采用
- 决策：默认统计一次实际按键，不把操作系统长按重复视为多次按键

原因：热力图更能反映用户实际按键习惯，避免长按方向键或删除键造成计数失真。后续可提供高级选项切换统计规则。
