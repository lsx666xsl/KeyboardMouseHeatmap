# KeyboardMouseHeatmap

一个 Windows 优先、离线运行的键盘与鼠标使用统计可视化工具。

## 当前状态

- 阶段：项目规划完成，准备初始化 Tauri 工程
- 技术路线：Tauri 2 + Rust + Vue 3 + TypeScript + SQLite
- 当前版本：规划阶段 `0.1.0`
- 隐私原则：默认只保存聚合统计，不保存用户实际输入的文本内容

## 目标功能

- 键盘按键次数统计
- 鼠标左键、右键、中键、侧键和滚轮统计
- 键盘和鼠标模板上的动态热力图
- 按键/鼠标控件上显示具体数据
- 今日、本周、本月和自定义时间范围筛选
- 时间趋势图和基础统计卡片
- 活泼、丰富、年轻化的视觉主题
- 本地运行、可暂停记录、可清空数据

## 开发环境

- Windows 10/11
- Node.js 与 npm
- Rust stable 与 Cargo
- Tauri CLI 2
